# 键盘保卫花园 · Type vs Zombie

面向初次接触电脑的小朋友的打字游戏。看清僵尸头顶的字母，按顺序输入，帮助五路豌豆射手守住花园。项目使用 React、TypeScript、Phaser 3 和 Vite，无需后端服务。

## 功能

- **循序渐进的课程**：第一大关共 10 小关，从 F、J 开始，逐步学习基本键位、分号与空格；包含键位演示、手指提示和静止试按。
- **无尽模式**：随波次增加僵尸种类、数量和速度，按输入准确率与反应时间强化薄弱键。
- **自由练习**：字母组合与短单词挑战。
- **五路战场**：角色行走、射击、受击、护具脱落、掉落奖励、镜头移动和通关庆祝。
- **四种道具**：樱桃炸弹、火爆辣椒、寒冰菇、毁灭菇；原版素材驱动的动作、粒子和音效。
- **无限道具开关**：普通关卡和无尽模式均可开启；开启后无限使用，停止道具卡掉落。
- **指法辅助**：美式键盘与双手高亮提示，可分别隐藏；布局随窗口尺寸调整。
- **本地存档**：课程进度、最高分、设置和无尽练习记录保存在浏览器 localStorage。

## 本地启动

建议使用 Node.js 22.12 或更高版本及 npm。

```sh
npm install
npm run dev
```

打开 <http://127.0.0.1:5173/>。Windows 也可以双击 `启动游戏.cmd`，保持服务窗口运行。

```sh
npm test          # 游戏规则回归测试
npm run build    # TypeScript 检查与生产构建
npm run preview  # 预览生产构建，地址以终端输出为准
```

仓库包含运行所需的 `public/game/` 素材，启动不需要重新提取本机游戏资源。

## 如何玩

使用电脑实体键盘和英文输入法，按僵尸头顶的字符顺序输入；大小写均可，空格显示为 `␣`。普通、路障、铁桶分别需要 1、2、4 个字符。输入错误不会清空进度，当前目标标签会闪红。

无尽模式中的僵尸可以超越，但当前输入目标保持锁定；消灭后再选择离终点最近的僵尸。每局有三次守护机会，僵尸越过守护线会扣除一次。

| 操作 | 按键 |
| --- | --- |
| 输入目标字符 | 对应字母、分号或空格 |
| 樱桃炸弹：目标附近三路范围爆炸 | 1 |
| 火爆辣椒：清除目标所在整路的可见僵尸 | 2 |
| 寒冰菇：冻结进入防守区的僵尸 6 秒 | 3 |
| 毁灭菇：目标附近更大范围爆炸 | 4 |
| 暂停 / 继续 | Esc |
| 教学演示继续、准备出发、通关进入下一关 | 按任意键，按界面提示操作 |

默认仅无尽模式掉落道具卡：首次按数字拾取，再按数字释放。持有或地面已有同类卡片时不会重复掉落。菜单开启无限道具后，无需拾取即可反复释放，所有关卡适用。没有目标时不会消耗道具；暂停不推进道具动作和冻结计时。

菜单可选关或切换模式；设置可调整速度、音乐、音量、音效和辅助提示。切换窗口会自动暂停。浏览器按 F11 可切换浏览器全屏。

## 第一大关课程

| 关卡 | 内容 |
| --- | --- |
| 1-1 | F / J 定位，单字母、单跑道 |
| 1-2 | F / J 交替，加入两字母路障 |
| 1-3 | D / K，中指定位 |
| 1-4 | F / D / J / K 混合，五条跑道 |
| 1-5 | 静止靶练习，加入四字母铁桶 |
| 1-6 | S / L，无名指定位 |
| 1-7 | A / 分号，小指定位 |
| 1-8 | G / H，食指伸出并回位 |
| 1-9 | 空格，拇指练习 |
| 1-10 | 基本键位综合挑战 |

课程依次解锁。当前仅实现第一大关；不包含 Shift 教学、退格纠错、触屏输入键盘、账号或云端同步。

## 无尽练习算法

参考 [Keybr](https://github.com/aradzie/keybr.com) 的按键熟练度、渐进解锁与目标键练习思路，独立实现适合游戏的出题逻辑，未直接复用其完整算法或词库。

算法区分首字符找键耗时与后续连续输入耗时，结合准确率和指数平滑更新熟练度，重点练习薄弱键。候选单词需符合已开放键位与僵尸所需字符长度；没有合适单词时生成字符组合。正常课程不受无尽模式的薄弱键统计影响。

## 素材与实现说明

这是个人学习项目，与《植物大战僵尸》的权利方无关联。游戏图片、音乐、音效等第三方素材的权利归各自权利人所有；仓库公开不表示这些素材可以自由再分发或商用。

早期资源来自本机 pvzHE 提取包。由于杂交版会修改贴图与动画，部分资源已替换为原版提取数据，来源见 [素材说明](assets/pvz/classic/README.md)。运行时在 Phaser/Canvas 中适配原动画轨道和粒子参数，规则与表现并非原游戏引擎的逐像素完整复刻。

完整的本机原始资源 `assets/pvz/raw/` 不纳入仓库。部分转换工具需要该目录中的原始文件；仅运行游戏无需使用这些工具。浏览器自动化检查工具可能需要本机 Playwright 环境。
